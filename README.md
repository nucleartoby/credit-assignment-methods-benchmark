## Maintaining this template

New project repositories are copied from this one, once, when they're created; changes here don't reach existing projects. So:

- Keep shared tools (the experiment tracker, compute helpers used everywhere) in their own repositories and install them as packages. Here, only add the dependency and the minimum setup, so projects get fixes by bumping a version.
- Keep only what every new project should start with.
- Delete this section from a project's copy.
